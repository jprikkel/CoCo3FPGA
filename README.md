# CoCo3FPGA 

This is a repository for the CoCo3FPGA project from Gary Becker which was maintained via a Yahoo Group that no longer exists.

"CoCo3FPGA is a Verilog/VHDL implementation in a programmable FPGA of a Tandy Radio Shack Color Computer 3 (CoCo3). It gives a super set of the functionality of the original CoCo3. CoCo3FPGA version 4.0 is implemented into a TerASIC DE-1. This board has almost everything needed to implement the CoCo3 in an FPGA. An additional analog add on board is required for some additional functionality including Joysticks. But this additional hardware is not needed for basic CoCo3 functionality. This full release of CoCo3FPGA includes the programming files, .sof and .pof, for DE-1 with the newer SRAM and the older SRAM chips. It also includes the Verilog/VHDL source code."

This repository is the CoCo3FPGA 4.0 update to the CoCo3FPGA 3.0 repository at https://github.com/richard42/CoCo3FPGA. This fork updates the files to match those found on a zip file on archive.org from 2022. The files are under the 2022 folder and from CoCo3FPGA_4.1.zip\CoCO3FPGA_Common\ file structure.

The `2022/` directory contains the accompanying 2022 source archives and as well as a port to the DE-2 and analog board materials for Eagle.
